UCF WebXR Experiences

A collection of three interactive educational simulations built for the browser. Each one works with mouse, touch, and keyboard, offers an accessible mode, and adds immersive VR as a progressive enhancement when a WebXR headset is available.

About this collection

These experiences were built for education at the University of Central Florida. Every experience runs as a plain static website: no installs, no accounts, no plugins. WebXR is a progressive enhancement - if a VR headset is connected and the browser supports immersive sessions, an Enter VR option appears, but nothing requires one.

Each experience includes an accessible, screen-reader-friendly way to complete the same learning activities, and each can be used entirely with a keyboard.
